# TSDGL

Temporal-context-aware Sparse Directed Graph Learning for Spatio-temporal Forecasting

## Overview

TSDGL models sparse and time-varying spatial dependencies for spatio-temporal forecasting. It learns temporal representations for dynamic spatial structure inference and uses directed relation strengths to guide adaptive neighbor selection and spatial propagation.

The framework consists of two components:

- **Temporal Hierarchy-Aware Attention Module (THAM):** Captures node-wise local temporal dynamics and dependencies across the observation window to support dynamic spatial structure inference.
- **Asymmetric Adaptive Spatial Propagation Module (AASPM):** Estimates directed relations and uses their relative strengths to select relevant neighbors and guide spatial information aggregation.
